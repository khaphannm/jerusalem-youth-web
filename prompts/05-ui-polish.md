# UI Polish Prompt

Polish the visible UI for `[PAGE/FEATURE]` without changing product scope.

First inspect:
- `docs/04-design-system.md`
- existing design tokens
- shared components
- the current page at mobile and desktop widths

Goals:
- stronger hierarchy
- more intentional spacing
- authentic editorial/ministry feel
- excellent mobile composition
- consistent component use
- accessible contrast/focus
- restrained motion
- no performance regression

Do not:
- invent a new brand palette,
- add gradients/glassmorphism by default,
- introduce an animation package without necessity,
- redesign navigation/information architecture,
- replace real content with decorative filler,
- create arbitrary one-off token values.

After changes, provide before/after screenshots if the environment supports them and run relevant checks.
