# Architecture Change Prompt

Evaluate this proposed architecture change:

`[CHANGE]`

Do not code yet.

Read:
- `docs/05-technical-architecture.md`
- relevant ADRs
- affected source structure

Return:
1. Problem being solved
2. Whether existing architecture already solves it
3. Options (maximum 3)
4. Tradeoffs
5. Recommended option
6. Migration/rollback impact
7. Whether an ADR is required

Prefer the least complex option that satisfies real requirements.
Only implement after the decision is approved.
