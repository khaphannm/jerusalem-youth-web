Date: 12 November 2026.
Status: Draft for ministry review. No text in this document has been published.

Vietnamese is the first release language. English below each section is a draft
translation for the later English release, not a promise that language switching
or translated CMS content already exists. Keep Jerusalem Youth as the brand name.

Primary destination supplied by the ministry:
