# Product Scope V1

## In scope

### Public pages
- Home
- About
- Events listing
- Event detail
- Articles/Devotionals listing
- Article detail
- Sermons listing
- Sermon detail
- Stories/Testimonies listing
- Story detail
- Media
- Resources
- Join Us
- Contact
- Search
- 404 / not found

### CMS capabilities
- About Page
- Article
- Event
- Sermon
- Testimony
- Resource
- Author
- Category
- Series
- Site Settings
- Navigation
- Social Links
- Draft/publish workflow
- Media management
- Role-based access

### Platform capabilities
- Responsive layout
- SEO metadata
- Open Graph/social sharing
- sitemap and robots
- structured data where appropriate
- analytics
- error monitoring
- image optimization
- caching/revalidation
- automated checks in CI
- backup strategy

## Out of scope for V1

Do not implement without an approved scope change:
- member accounts/login
- member profiles
- small-group management system
- prayer-request workflow/database
- custom event registration engine
- donation/payment processing
- chat/messaging
- mobile app
- push notifications
- CRM
- advanced personalization
- multilingual support unless formally added
- custom video hosting/streaming

External forms/registration links are acceptable for V1.

## Core user journeys

### New visitor
Social/search/referral → Home or content page → understand ministry → see event/content → Join/Contact.

### Returning visitor
Direct/social → latest event/article/sermon → consume/share → next content or action.

### Content editor
CMS login → create/edit draft → preview/review → publish → website updates.

## Scope-change rule

Any proposed feature outside this document requires:
1. problem statement,
2. user value,
3. complexity/operational impact,
4. effect on launch,
5. explicit product-owner decision.

Do not silently expand V1.
