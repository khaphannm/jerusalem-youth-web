# Visual Consistency Checklist

Use this checklist for every visible UI story and before release.

## Brand
- [ ] Uses only approved semantic color tokens
- [ ] No arbitrary raw brand hex values in components
- [ ] No unapproved Tailwind palette colors
- [ ] Visual direction still reads as Modern Editorial Youth Ministry
- [ ] Page does not look like a generic SaaS/startup template
- [ ] Page does not look like a one-off event/conference microsite

## Hierarchy
- [ ] One clear primary action per section
- [ ] Headings have intentional scale and rhythm
- [ ] Body copy is easy to scan/read
- [ ] Section spacing follows the design system
- [ ] Empty space is intentional

## Color
- [ ] Primary Blue is used for primary interaction/brand emphasis
- [ ] Coral is reserved for energetic highlights
- [ ] Sage is reserved for calm/reflective content
- [ ] Navy/Midnight provide strong anchors where appropriate
- [ ] Contrast passes WCAG 2.2 AA
- [ ] State is not conveyed by color alone

## Components
- [ ] Shared components are reused
- [ ] Radius follows 6/12/20px scale
- [ ] Shadows are minimal
- [ ] Cards are not mechanically identical when content types need different treatment
- [ ] Buttons are not pill-shaped by default

## Photography
- [ ] Authentic ministry photography is preferred
- [ ] Crop/aspect ratio supports hierarchy
- [ ] Alt text is meaningful where needed
- [ ] No oversized/unoptimized imagery
- [ ] Decorative treatment does not obscure authenticity

## Motion
- [ ] Motion serves state/hierarchy/interaction
- [ ] No decorative animation overload
- [ ] Reduced-motion preference is respected

## Responsive
- [ ] Mobile composition is designed, not merely stacked
- [ ] Touch targets are comfortable
- [ ] Typography scales cleanly
- [ ] No horizontal overflow
- [ ] Important CTA remains clear on small screens
